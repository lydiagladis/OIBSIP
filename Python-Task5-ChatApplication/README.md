# Chat Application

## OIBSIP Task 5

A simple Python command-line chat application using sockets and threading. It allows two clients to communicate in real time on the same computer using localhost.

## Features

- Server listens for incoming client connections.
- Client connects to the server.
- Two users can exchange messages in real time.
- Messages include timestamps and usernames.
- Displays a notification when a client disconnects.
- Runs on localhost.

## Technologies Used

- Python
- Socket Programming
- Threading
- DateTime

## How to Run

2. Open Terminal 1 and run:
